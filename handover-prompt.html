## HARD CONSTRAINTS — MUST FOLLOW

1. **NEVER click** `aria-label='Delete automation'` or `aria-label='Execute automation now'` (costs quota, no undo)
2. **"Publish to community skills" toggle must stay OFF** — assert it, never enable it
3. **NEVER use `waitForLoadState('networkidle')`** — the app holds open sockets, it ALWAYS times out
4. **Use `waitUntil: 'domcontentloaded'`** on ALL `waitForURL()` and `goto()` calls
5. **Do NOT print, commit, or log `.env` contents or `.auth/user.json` contents**
6. **Use `pressSequentially()` for typing on the main composer** `textarea[data-slot="textarea"]` — `fill()` gets wiped by React re-render. This applies ONLY to the composer, NOT to drawer/form inputs (those can use `fill()`)
7. **Overlay fix in every beforeEach**: `document.documentElement.style.pointerEvents = '';` — the `` element intercepts pointer events after modal/popover interactions
8. **Session expires frequently** — if tests fail with login page shown, run `node auth.js` to refresh before retrying
9. **Use `force: true` on clicks** when overlay issues persist

## TECHNICAL PATTERNS (copy from existing tests)

### Test file structure:
```javascript
const { test, expect } = require('./fixtures');
const { SomePage } = require('../pages/SomePage');

test.describe('Page Name', () => {
  test.describe.configure({ mode: 'serial' });
  let pg;

  test.beforeEach(async ({ page }) => {
    pg = new SomePage(page);
    await page.evaluate(() => {
      document.documentElement.style.pointerEvents = '';
      document.body.style.pointerEvents = '';
    }).catch(() => {});
    await pg.goto();
    await page.waitForTimeout(1000);
  });

  test('test name here', async ({ page }) => {
    test.setTimeout(60_000);
    // test code
  });
});
```

### Key patterns:
- **Empty workspace guard**: Check `.isVisible().catch(() => false)` before asserting elements that may not exist
- **Section count check**: Extract count from text like "URL Imports (4)" before trying to interact with items inside
- **Duplicate dialog handling**: After import/add, check for "Re-import" or "already exists" dialogs
- **Timestamps for uniqueness**: Add `Date.now()` to test data to avoid duplicate conflicts
- **ZZTEST prefix**: All test-created data uses "ZZTEST" or "zztest" prefix for easy identification and cleanup
- **Cleanup tests at end**: Delete any ZZTEST entries created during the test run
- **Scroll before interact**: `scrollIntoViewIfNeeded()` for elements below the fold
- **Rate limiting on email fetch**: Add 1-2s delay between `api/email/fetch` calls
